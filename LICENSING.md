## About this repository and 0.15.2

The root LICENSE and THIRD_PARTY notices reproduce the files supplied with the
Tidycade 0.15.2 Ubuntu and Windows downloads. Their contents were checked against
both release archives and the matching application source. This file retains the
release's licensing explanation above and adds this repository-specific context.
No new licensing terms are introduced here.

The `app/` paths above refer to the application source tree, which is maintained
privately, not to paths published in this repository. In the distributed launcher,
game image credits and notices are available through each game's Credits view.
See [THIRD_PARTY/NOTICES.md](THIRD_PARTY/NOTICES.md) for runtime notices and the
locations of downloaded catalogue notices.

for individual games, game artwork, brands or bundled third-party components.

third-party source materials supplied with the release:
